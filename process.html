v0 → v1 실행 · AI 채택

먼저, 식물답게.

축마다 달랐던 배율을 맞추고, 원형 끝점을 방향 있는 잎으로 바꿨다. 줄기·잎·지면의 위계와 제한된 색을 더했다.

관찰: 세로 가지와 잎 방향이 읽히고 오른쪽 수관이 화면 안에 들어왔다. 클릭·초기화·PNG·모바일 가로 넘침 smoke에서 회귀가 관찰되지 않았다.

v1 → v2 실행 · 채택

다음은, 편안한 조작.

방향키·Enter/Space 심기, 대체 심기 버튼, 시스템·수동 동작 줄이기, RAF 시작·취소와 배경 캐시, 모바일 제어 배치를 개선했다.

실행: 키보드 심기 5→6, 정지·동작 줄이기 RAF 각 0회, 조작 영역 44px. 최종 픽셀 복귀 결함도 수정했다. 검증 기록과 실행 원본으로 확인한다.

비교를 읽는 방법 viewport는 같지만 Canvas 높이는 v0 550 → v1 630 → v2 약777px로 변경됐다. 화면 구성도 실험 변수이므로 형태 변경의 효과만 따로 수치화하지 않는다. 미적 만족은 자동 시험과 별개의 판단이다.
