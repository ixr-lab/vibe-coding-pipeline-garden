# 요구·평가 기준 — 구현 전 고정

기록일: 2026-10-17 UTC. 작성 주체: AI 구현자. 사용자의 직접 미적 승인을 받은 문서가 아니다.

## 1. 목표와 맥락
‘인터랙티브 생성형 정원’은 작은 브라우저 작품이자 AI 협력 개발 과정을 재현하는 사례다. 사용자는 씨앗을 심고 자라는 가지와 잎을 보며 바람·밀도·seed를 바꾼다. 핵심 산출물은 동작하는 코드, 두 차례 실제 개선, 동일 조건 증거와 판단 기록이다.

## 2. 범위와 구현자의 선택
- 의존성 없는 HTML/CSS/Canvas 2D/일반 JavaScript. index.html 직접 열기와 로컬 HTTP 지원.
- 클릭/터치 심기, seed 재생성, 잎 밀도, 바람, 일시정지/재개, 빈 정원 초기화, PNG 저장.
- 데스크톱/모바일, 키보드로 위치 이동·심기, 동작 줄이기와 시스템 설정 존중.
- 기존 전주/자개/LidarTouch 자산은 읽거나 변경하지 않는다. 이 독립 폴더만 저장한다.
- 서버, 계정, 유료 API, 공개 배포, 생물학 시뮬레이션은 범위 밖.
- 디자인 선택: 종이 같은 밝은 배경, 짙은 잉크색, 세이지/황토색 식물, 여백과 작은 실험실 표기. AI의 제안이며 사용자 취향 승인은 확인 대기.

## 3. 변경 전 고정한 비교 기준
| ID | 기준 | 판정 방법 | 목표 |
|---|---|---|---|
| F1 | 씨앗 심기·성장 | 브라우저 입력 + 시간/식물 수 관찰 | 클릭/키보드 각 1개 증가, 성장 시간 증가 |
| F2 | 재현 가능성 | engine 단위 시험 + 고정 URL 캡처 | 같은 seed·입력 순서·설정·성장 시간에 같은 데이터/픽셀 |
| F3 | 조절·정지·초기화·저장 | 실제 브라우저 시험 | 상태 반영, 정지 중 시간 고정, 초기화 0개, PNG 유효 |
| V1 | 가지와 잎 식별 | 동일 조건 화면 육안 비교(AI) | 성장 위계와 잎 방향이 읽힘 |
| V2 | 미적 정돈 | 동일 화면 육안 비교(AI) | 제어·작품의 위계, 여백, 색 일관성 |
| A1 | 키보드 | 실제 브라우저 입력 | Tab 접근, 방향키 위치 이동, Enter/Space 심기 |
| A2 | 동작 줄이기 | media emulate + 토글 | 성장 즉시 완성, 흔들림/연속 RAF 중지 |
| A3 | 모바일 | 390×844 CSS viewport | 가로 넘침 없음, 터치 대상 약 44px 이상 |
| P1 | 상한과 실행 비용 | 데이터 상한 + 브라우저 측정 | 최대 32식물, DPR ≤2, 120프레임 측정값 공개 |
| D1 | 증거의 정직성 | 문서/커밋/원본 이미지 확인 | v0/v1/v2, 실제 관찰과 계획 구분 |

기준 변경 시 이 문서에 날짜·이유를 추가한다. 아직 변경 없음. 성능 측정은 이 환경의 참고치이며 모든 기기 60fps를 보증하지 않는다.

## 4. 고정 비교 프로토콜
seed=271828, density=7, wind=35, growth tick=360(60Hz 환산 6초), viewport=1440×1000, deviceScaleFactor=1, Chromium. URL의 `frame=360`은 자동 성장/바람 시간을 고정하는 재현용 보기다. 기본 배치는 동일한 정규화 좌표의 5개 식물. 파일 직접 열기에서도 URL 쿼리를 붙일 수 있다. 모바일 보조 캡처는 390×844. 이미지의 아름다움은 자동 시험 통과와 별개다.

## 5. AI와 사람의 경계
AI: 자료 수집, 설계 선택, 구현, 실행, 원인 가설, 기술·시각 비교, 결함 수정, 증거 수집.
사람: 미적 만족, 원하는 분위기와 활용 가치, 공개 전환/배포 결정. 사람의 직접 승인 기록을 만들지 않는다.
