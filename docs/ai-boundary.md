# AI와 사람의 판단 경계

이 프로젝트는 AI가 설계·구현·실행·비교한 생성형 정원 사례입니다. 기술 시험의 통과, AI의 시각 판단, 사람의 미적 만족을 서로 다른 근거로 기록합니다.

## AI가 수행한 일

- 독립 폴더 안의 HTML/CSS/JavaScript 구현과 개발용 시험을 작성했습니다.
- [공식 레퍼런스](references.md)를 실제 조회하고 원리를 해석했습니다. 타인의 코드·이미지를 복사하지 않았습니다.
- [요구·평가 기준](requirements.md)을 구현 전에 정하고 [계획](plan.md), [로그](log.md), [실험](experiments.md)을 남겼습니다.
- v0 실행 화면에서 부족점을 관찰하고 v1 렌더 개선, v2 입력·모션·모바일 개선을 실제 실행했습니다.
- [원본 PNG·JSON·텍스트](../evidence/)를 수집하고, 밀도 왕복 픽셀 결함과 시험 자체의 대기·부동소수점 비교 오류를 구분해 교정했습니다.

다른 AI 에이전트의 조사·리뷰도 AI 작업입니다. 사람의 독립 검토나 승인으로 표시하지 않습니다. 레퍼런스의 권위는 이 구현의 정확성·미적 품질을 자동으로 보장하지 않습니다.

## 근거별로 말할 수 있는 것

| 근거 | 뒷받침하는 주장 | 대신하지 못하는 판단 |
| --- | --- | --- |
| Node·브라우저 실행 기록 | 해당 입력·환경에서 검사한 동작의 결과 | 모든 기기·브라우저의 무결함 |
| 고정 조건 원본 이미지와 AI 관찰 | 형태·배치가 어떻게 바뀌었는지와 AI의 채택 이유 | 사용자의 취향·아름다움에 대한 동의 |
| 키보드·RAF·크기 감사 | 감사한 조작과 동작 줄이기의 개선 | WCAG 준수, 스크린리더 사용성 전체 |
| 한 환경의 RAF 간격 | 그 실행의 콜백 사이 시간 분포 | 독립 렌더 시간, 보편적 성능 보증 |
| 시험 중 외부 요청 없음 | 관찰한 세션에 HTTP/HTTPS 요청이 없었음 | 보안 인증·취약점 부재 |

## 사람에게 남는 판단

‘여린 정원’의 분위기·색·속도·쓸모가 원하는 경험에 맞는지, AI의 시각 개선을 채택할지는 사람이 판단합니다. **사용자의 미적 만족과 직접 승인은 확인 대기**입니다. 작업 위임이나 자동 시험 통과를 미적 승인으로 해석하지 않습니다. 공개 전환·배포 판단도 별도입니다.

GitHub 업로드나 파일 전달은 계획과 실행 확인을 구분합니다. 이 문서는 원격 생성·업로드·전달 성공을 증명하지 않으며, 실제 확인된 URL과 결과가 있어야 완료로 기록할 수 있습니다.

## 남은 검증

현재 모바일 증거는 390×844 뷰포트·터치 에뮬레이션입니다. 실기기, Firefox, Safari, 스크린리더는 미검증입니다. [시험 기록](tests.md)의 제한과 최신 JSON을 함께 읽어야 합니다. 실패 원본은 학습과 재현의 일부이며, 이후 성공이 과거 실패를 없애지는 않습니다.
