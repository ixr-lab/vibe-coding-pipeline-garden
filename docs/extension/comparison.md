# 꽃·브러시 확장 시각 비교

2026-10-17 UTC. [실행 전 기준](plan.md), [실제 작업 로그](log.md), 버전별 PNG를 바탕으로 작성했다. 직접 관찰한 외부 원본의 출처·제작자·권리·접근일은 [꽃 자료](../../reference-source/flowers.json)와 [브러시 자료](../../reference-source/brushes.json)에 있다. AI의 개선 채택 판단이며 사용자의 미적 승인은 확인 대기다.

## 무엇을 비교했는가

외부 기준은 실제 꽃 사진과 Krita 공식 디지털 브러시 샘플이다. 둘을 같은 성격의 자료로 취급하지 않는다. Winsor & Newton의 실제 화구 설명은 문서로 읽었으며 해당 영상·실물 스트로크를 직접 관찰한 근거로 쓰지 않았다. 외부 원본은 저장소 밖 `reference-study/flowers`·`reference-study/brushes`에만 보관했고 사이트나 비교 도판에 재배포하지 않았다.

이 저장소의 `v3/v4/v5-flowers.png`, `*-brushes.png`, `*-combinations.png`와 `current-*.png`는 자체 코드가 실제 Canvas에 그린 출력이다. 사진이나 외부 샘플의 복제본이 아니다. 브러시 비교는 `study.js`의 같은 quadratic 경로·색 `#3f6450`·명목 폭 `18`·질감 `60`·농도 `85`·seed `271828`로 고정했다. 경로 좌표는 (240,75)→control(600,-25)→(1130,75)이며 행마다 y만 평행 이동한다. 조사 초안의 S곡선·24px 조건은 채택하지 않았으며 source JSON도 실제 조건으로 동기화했다. X교차·재추적·실시간 필압은 미검증이다. 압력 잉크는 경로를 따른 절차적 폭 변화이며 실제 펜 입력을 측정한 결과가 아니다.

꽃 클로즈업은 같은 seed, 중심·크기·각도에서 종별 윤곽·곡률·겹침·중심·줄기 연결을 본다. 전체 정원은 seed271828/density7/wind35/frame360 조건이다. 화면 구성 변경으로 전체 Canvas 높이가 달라질 수 있어, 전체 정원 스크린샷의 모든 픽셀 차이를 형태 수정의 효과로 해석하지 않는다.

## 채택 범위

v4 꽃 형태 개선과 v5 꽃 아래 접합 보정은 채택했다. 펜·잉크는 유지했고, 드라이는 재료 구분이 개선되었다. 연필·수채는 부분 개선으로 남긴다. 사진과 완전히 같은 꽃, 실제 재료를 계산하는 브러시, 사용자 미적 승인 완료라는 주장은 하지 않는다. 외부 원본과 현재 출력의 차이 및 원본에서 보이지 않은 구조를 계속 분리해 기록한다.
