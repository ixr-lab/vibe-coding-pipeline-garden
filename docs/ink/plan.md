# 수묵·담채 전환 계획

2026-10-17 UTC. v11 꽃잎 재료 개선 뒤 사용자가 꽃잎 색 선택, 꽃머리만 강조되는 비율의 개선, 수묵·담채 연출을 요청했다. 이전 P1~P6의 충족 여부는 이 새 의도의 충족을 뜻하지 않는다. 기존 태그·화면·시험은 보존하고 새 I1~I6 기준으로 판정한다. 아래 비율과 배치는 구현 전 가설이며 역사 회화의 보편 규칙이나 식물학적 사실로 제시하지 않는다.

## 고정한 비교 기준

| 기준 | 확인할 결과 | 확인 방법 |

## 순서와 범위

1. 공식 소장처의 수묵·담채 화훼 작품을 실제 이미지로 관찰하고 레퍼런스 페이지를 먼저 갱신한다. 작품별 차이와 적용/회피 지점을 적는다.
2. v12에서 새 식물 모델, 연결된 곡선·잎군, 종이 배경, 수묵/담채와 색 선택을 통합한다.
3. 실제 동일 조건 화면을 실행하고 원인을 기록한다. v13과 v14에서 최소 두 번 개선하고 각 소스 태그·실행 화면을 보존한다. 필요한 추가 수정은 별도 버전으로 기록한다.
4. 제작자와 독립 리뷰어가 전체 실루엣·근접 재료·공식 레퍼런스를 함께 검토한다. 사람의 최종 취향 승인은 확인 대기로 남긴다.
5. 기능·성능·접근 입력·출처·개인정보를 검사하고 이미 public인 이 저장소에만 새 변경을 올린다. Pages 배포나 다른 저장소 변경은 하지 않는다.

## 구현 가설

- 옛 이진 분기 모델 대신 주줄기와 짧은 곁줄기, 중하부 잎군을 사용하면 꽃머리를 지탱하는 몸체가 읽힐 것이다. 기존 엔진 API는 과거 재현을 위해 보존한다.
- 꽃 지름:보이는 줄기 길이 약 1:8~12, 아래쪽 큰 잎·위쪽 작은 잎, 드문 위쪽 잎을 출발점으로 삼는다. 종별 형태와 실행 화면에 따라 조정한다.
- 다섯 초기 포기를 세 무리로 두고 중심 주역과 낮은 응답 포기를 섞으면 규칙적 나열을 줄일 수 있다.
- 담채는 저채도 안료색을 꽃잎에 두고 중심·줄기·잎은 먹으로 묶는다. 수묵에서는 선택색을 보관하되 화면 전체를 중성 먹으로 그린다.
- 캐시와 seed 결정성은 유지하며 색 변경 시 캐시 키를 바꾼다. 매 프레임 이미지 픽셀을 읽어 색을 바꾸지 않는다.

비교 기본 조건은 seed `271828`, 뷰포트 `1440×1000`, DPR `1`, `frame=360`, 밀도 `7`, 바람 `35`다. 모바일은 `390×844`를 별도로 확인한다. 구조 비교의 주 표본은 코스모스·압력 먹·담채 기본색이며, 모든 종/브러시 조합도 별도로 비교한다.
