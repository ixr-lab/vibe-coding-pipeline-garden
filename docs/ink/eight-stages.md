# 수묵·담채 전환의 8단계

기존 v0~v11의 코드·태그·실행 증거를 보존한 후속 작업이다. 꽃잎 색 선택과 기본색 복원, 꽃머리를 지탱하는 전체 식물 비율, 수묵·담채의 표현을 [I1~I6](plan.md)으로 다시 평가한다. 아래는 실제 완료한 단계와 진행 중인 단계를 구분한 기록이다.

| 단계 | 수행과 근거 | 현재 상태 |
|---|---|---|
| 1 목표와 맥락 | 꽃머리만 강조되는 비율과 색 선택 요구를 새 목표로 고정. 이전 P1~P6를 새 목표의 충족 근거로 사용하지 않음 | [계획](plan.md) 고정 |
| 2 레퍼런스와 기준 | 공식 소장처의 회화 3점을 실제 이미지로 관찰하고 국가·시기·재료·작자 귀속을 기록. 기존 11개와 함께 보드를 먼저 갱신 | 구현 전 커밋 `b2db131`, [화면](../../evidence/ink/reference-before-implementation.png)·[JSON](../../evidence/ink/reference-before-implementation.json) 보존 |
| 3 설계와 범위 | 옛 엔진 API를 보존하면서 연결된 곡선 줄기·짧은 곁줄기·잎군·꽃받침을 새 모델에 추가. 수묵/담채·선택색은 렌더 옵션과 캐시 키에 반영 | 새 모델과 색 UI 통합 |
| 4 최소 구현 | v12 첫 실행. 전체 정원·수묵/담채·선택색·모바일 캡처. 단독 표본의 재료 seed 누락은 뒤에 발견해 v12 소스를 재실행한 v12-r2로 교정 | 소스 `d63b83b`, [첫 실행](../../evidence/ink/v12-capture.json)·[재캡처](../../evidence/ink/v12-r2-capture.json) 보존 |
| 5 실행과 비교 | 제작자가 실제 PNG를 열어 레퍼런스의 줄기 흐름·잎과 여백과 비교. 연결은 개선됐으나 동일한 세 갈래 잎군과 중간 영역 과밀을 관찰 | v12 부분 채택, [비교](comparison.md) |
| 6 가설과 반복 | v13에서 잎군 수7→5·종별 잎·S곡선·간격을 개선. 와이어 같은 잎과 옅은 연결을 보고 v14에서 중하부 먹잎군·농담·재료별 구조선을 개선. 별도로 발견한 성장 중 잎 분리도 수정 | v13 `6dfb850` → v14 `ff638fa`, [실제 비교](comparison.md)와 성장 [PNG](../../evidence/ink/growth-before-after.png) 보존 |
| 7 통합과 판정 | 실제 기능127/127·접근17/17·전체 식물/근접52/52·Node23/23·페이지132/132 통과와 최대 장면 성능 관찰. 제작자와 독립 리뷰어는 I1/I2/I4 채택, I3 부분 채택 | [시험](tests.md)·[시각 리뷰](visual-review.md)·[코드 리뷰](code-review.md), [출처/이력 재감사](publication-audit.md) findings0/errors0 |
| 8 전달과 재사용 | 실행법·버전 비교·판단 경계를 한국어 문서로 연결. 같은 public 저장소에 main과 새 태그3개를 실제 전달 | [재현](reproduce.md)·[전달](delivery.md), [원격 파일29개·태그15개·비인증 파일3개 검증](../../evidence/ink/remote.json). 별도 ZIP/Library ID는 최종 보고 |

AI 제작자·독립 AI 리뷰어의 판단과 사용자의 직접 승인은 별개다. 색감·추상화 정도·전체 구도의 최종 만족은 **확인 대기**다. [작업 로그](log.md)는 의도 → 가설 → 변경 → 실행 → 관찰 → 채택/보류의 순서를 보존한다.
