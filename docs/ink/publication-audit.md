# 수묵·담채 공개 이력 감사

대상은 `ixr-lab/vibe-coding-pipeline-garden`의 main과 v0~v14 태그뿐이다. 저장소는 새 요청 전에 이미 public이었고 이후 가시성은 변경하지 않았다. 기존 `ixr-lab` 인증은 User 계정이며 이 저장소 push 권한을 확인했다. [확인 기록](../../evidence/ink/github-context.json). 새 OAuth/토큰·권한 확대, 다른 저장소 변경, Pages 배포를 하지 않았다.

## 첫 감사와 정리

[첫 감사](../../evidence/ink/privacy-audit-before.json)는 새 시험 JSON의 로컬 실행 경로 메타데이터 453건을 찾았다. 새 커밋을 push하기 전에 경로만 상대 표기로 정리했다. 원래 검사 결과·시각·PNG·제품 소스는 그대로다. [정리 영수증](../../evidence/ink/privacy-redaction.json)은 수정한 네 JSON blob과 커밋 대응을 기록한다. v12는 동일하고 공개용 v13은 `6dfb850`, v14는 `ff638fa`이다. 이미 공개된 v0~v11은 바꾸지 않았다. 현재 시험 도구도 결과/오류/로컬 링크에 절대 경로를 저장하지 않도록 수정했다.

## 재감사 실제 결과

[재감사 JSON](../../evidence/ink/publication-local.json)은 source v14 `ff638fa`에서 main·태그16개, Git commit19개·tree117개·blob468개와 당시 작업 후보506개를 읽어 **findings0/errors0**을 기록한다. 읽는 동안 선택 refs와 작업본은 안정적이었다. 개인 경로·인증값 패턴·대화 마크업·외부 이미지 삽입을 검사했다. PNG는 IHDR/IDAT/IEND 청크만 있었다. 이 기록은 생성 직전 HEAD와 작업 후보를 다루며, 최종 문서 커밋 이후에는 별도 최종 감사를 다시 수행한다.

외부 원본 회화/사진은 관찰을 위해 저장소 밖에서만 열었다. 소장처 URL·귀속·시기·재료·권리·관찰 범위를 텍스트로 연결하고, 앱과 비교 도판에는 직접 만든 Canvas·브라우저 출력만 포함한다. 원작 식물의 복제나 역사 회화의 완전한 재현으로 소개하지 않는다. 기계 패턴 검사는 모든 비밀이나 임의 이미지의 출처를 수학적으로 증명하지 못하므로 제작 경로와 독립 검토도 함께 확인했다.

## 판정과 업로드 범위

제작자·독립 시각 검토는 I1/I2/I4를 채택, I3을 부분 채택했다. 사용자 직접 취향 승인은 확인 대기다. 기능127/127·접근17/17·재료52/52·Node23/23·전체 페이지132/132, [성능 관찰](../../evidence/ink/stress.json)의 제한을 공개 문서에 적었다. 공개할 새 소스는 이 판정과 한계를 함께 제공한다.

push는 main과 새 v12/v13/v14 태그만 명시한다. 로컬 백업 refs·reflog·`.git`·외부 원본 자산은 전송하거나 ZIP에 넣지 않는다. push 뒤 정확한 원격 commit·주요 파일 바이트·v0~v14 태그·비인증 README/코드/PNG 조회를 확인한다. 결과는 전달 기록에 추가한다.
