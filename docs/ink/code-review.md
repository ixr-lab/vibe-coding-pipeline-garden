# 독립 코드 검토

2026-10-17 UTC. 구현에 참여하지 않은 AI 리뷰어가 실제 소스와 Node 시험을 읽었다. 파일 수정 없이 모드/색 경로, native Canvas 어댑터, 기하·경계·캐시·성장을 검토했다.

- v14 최종 Node 23/23 통과를 재확인했다. 기존 꽃 출력의 no-mode 경로, alpha·gradient·save/restore, mode/color와 캐시 키가 일치한다.
- v13의 성장 중 분리 결함을 수치로 확인하여 보고했다. v14의 실제 렌더 경로가 잎자루 완성 후 잎을 드러내는 함수를 사용한다. 32포기·밀도12·0~6초의 0.125초 간격 검사에서 잎자루가 미완성인데 보이는 잎 0건, 6초 미완성 잎 0건을 확인했다.
- 998×778·32포기·밀도12·선폭2.5의 성숙 sprite 면적 계산은 7,096,619px로 12,000,000px 예산 안이다. 이는 소스 계산이며 실측 FPS가 아니다.
- 중대 결함이나 남은 차단 요인은 발견하지 못했다.

경미한 합성 한계: watercolor의 국소 `destination-out` 마스크는 같은 sprite에 먼저 그린 밑그림의 알파도 일부 줄인다. 리뷰어의 Chrome 표본(daisy, seed271828/id2, 1000×778, opacity100)에서 2/255 이상 줄어든 픽셀 414개, 최대 감소 약 28/255를 관찰했다. 구조/기능을 깨는 수준으로 확인되지는 않았으나 물리적 안료 모사를 주장하지 않는 이유 중 하나다. 현재는 시각 한계로 남기며 [시험](tests.md)의 재료 한계와 함께 읽는다.
