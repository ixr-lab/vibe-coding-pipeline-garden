# 수묵·담채 전환 비교와 판단

[I1~I6](plan.md)는 구현 전에 고정한 새 기준이다. 과거 꽃잎 재료의 P1~P6 통과를 새 전체 식물 비율·구도의 통과로 이어 쓰지 않는다. 기본 비교는 seed271828, `1440×1000`, DPR1, frame360, 밀도7, 바람35, 코스모스·압력 먹·담채 기본색이다. [실행 조건](reproduce.md)과 [작업 로그](log.md)를 함께 읽는다.

첫 v12 전체 정원은 이 조건을 충족한다. 별도 한 포기/5브러시 표본은 harness에서 재료 상태의 seed가 누락된 문제를 발견했다. 모델 seed와 재료 seed를 함께 전달하는 수정 harness로 v12 태그를 다시 실행한 `v12-r2`를 후속 표본과 비교하며, 첫 PNG는 원본 기록으로 보존한다. 이 QA 교정을 제품 개선 횟수에 포함하지 않는다.

## v12에서 실제 본 점

주줄기는 꽃목까지 이어지며 휘고, 짧은 곁줄기와 처진 봉오리가 생겼다. 종이 바탕과 저채도 꽃잎은 색을 고르는 목적을 보여준다. 다만 코스모스에서도 넓고 뾰족한 잎 세 장이 반복되어 대나무 같은 부채꼴로 읽힌다. 중앙의 반투명 회색 잎이 중첩되어 줄기 사이 빈 공간이 사라지고, 다섯 포기의 배치도 규칙적인 정원 장식에 가깝다. 연결 개선만으로 목표를 완료했다고 판단하지 않는다.

## v14의 실제 도판과 성장 교정

[v14 정원](../../evidence/ink/v14-garden.png)·[3종 전체 식물](../../evidence/ink/v14-plants.png)·[다섯 브러시](../../evidence/ink/v14-brushes.png)·[모바일](../../evidence/ink/v14-mobile.png)을 제작자와 독립 리뷰어가 직접 열었다. 코스모스 중하부의 짧은 먹잎군과 연필 구조선이 연결을 보강한다. 넓은 잎의 그라데이션을 줄였지만 실제 먹의 국소 번짐·우연한 농도와 평평한 디지털 면의 차이는 남는다. 기본 코스모스는 비교의 연속성을 위해 유지했으며 원작의 연꽃·모란 잎을 다른 종에 강제하지 않았다.

- [v12→v13→v14 정원](../../evidence/ink/evolution.png), [v12↔v14](../../evidence/ink/before-after.png), [전체 식물 변화](../../evidence/ink/plant-evolution.png), [수묵·장미색·청색](../../evidence/ink/color-modes.png): 자체 실행 PNG를 비율 유지해 축소한 편집 패널. 원본 PNG는 그대로 보존했다.
- [v14 전체 식물15조합](../../evidence/ink/v14-materials.png), [꽃/꽃목·하부 잎군의 원배율 근접](../../evidence/ink/v14-materials-closeups.png), [52/52 검사와 crop 조건](../../evidence/ink/v14-materials.json): 실제 `300×580` Canvas를 그대로 붙이거나 crop했으며 리사이즈·재그림하지 않았다.
- [성장 중 실제 전후 PNG](../../evidence/ink/growth-before-after.png), [래스터 캡처 조건](../../evidence/ink/growth-raster.json): v13 소스와 v14 `ff638fa`, seed271828, 한 포기 데이지·펜·바람0·농도100, age2.125. 전에는 완성 위치의 잎이 자라는 잎자루보다 먼저 나타났고, 이후에는 잎자루가 완성될 때까지 잎을 숨긴다.

[별도 기하 검사5/5](../../evidence/ink/growth-connection.json)는 v13 문제 시점의 샘플 거리 약29.2px와 v14의 잎 노출 시점을 실사용 함수로 계산했다. 실제 픽셀에서 잰 거리가 아니다. 이미지 재실행과 계산 검사를 함께 보존하며 이 기능 수정도 v14 변경에 포함한다.

## 원본과 비교 범위

[공식 관찰 기록](reference-observations.md)은 중국 청대 Bada Shanren의 수묵, 일본 메이지기 Watanabe Seitei의 수묵·채색, 중국 청대의 **After Yun Shouping** 귀속 채색을 구분한다. 한국 수묵·담채의 대표를 조사했다고 주장하지 않는다. Bada Shanren의 DP205835는 두루마리의 한 부분이므로 전체 구도를 모두 보았다고 쓰지 않는다.

관찰한 줄기 농담·잎 겹침·꽃과 잎의 위계·큰 여백을 구현 가설로 옮긴다. 외부 작품을 다운로드 가능한 앱 자산으로 넣거나 외곽선을 추적하지 않는다. 비교 도판은 코드가 새로 그린 출력이다.

## 판정 상태

v12는 기능 검사를 통과한 첫 구현이며 시각 기준은 부분 채택이다. v13은 실제 화면에서 구조 개선을 채택하고 재료를 보류했다. v14의 제작자와 [독립 AI 리뷰](visual-review.md)는 I1 연결·I2 구도·I4 색 범위를 채택하고 I3 먹/종이를 부분 채택했다. I4 기능·I5 사용성은 실제 [시험](tests.md), I6 출처/이력과 원격 상태는 [전달](delivery.md)에서 확인한다. [독립 코드 리뷰](code-review.md)의 watercolor 국소 마스크가 같은 sprite의 밑그림 알파도 일부 줄이는 경미한 합성 한계 역시 남긴다. **사용자 직접 미적 승인과 최종 만족은 확인 대기**다.
