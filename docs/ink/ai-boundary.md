# 수묵·담채 작업의 AI와 사람의 경계

AI는 새 요구를 I1~I6로 정리하고 공식 소장처의 실제 회화 이미지를 관찰한 뒤, 전체 식물 모델·렌더·색 제어·시험·한국어 기록을 만들었다. 제작자와 독립 리뷰어 역할을 나눈 경우에도 모두 AI의 작업이다.

| 근거 | 뒷받침하는 주장 | 대신할 수 없는 판단 |
|---|---|---|
| 공식 카탈로그와 원본 관찰 | 작품별 작자 귀속·국가·시기·매체·부분 이미지의 범위와 눈에 보이는 특징 | 화가의 필순·실제 필압·물 양, 전통 전체의 대표성 |
| 구현 전 보드와 커밋 | 레퍼런스 관찰과 기준 고정이 앱 변경보다 앞섰음 | 그 해석을 구현이 충분히 실현했는지 |
| Node·실제 Chrome·픽셀 검사 | 해당 입력과 실행 환경의 동작·결정성·상태 복원·PNG 일치 | 모든 기기에서의 무결함, 재료의 미적 충실도 |
| 전체/한포기/근접 PNG와 AI 리뷰 | 형태·여백·농담이 어떻게 바뀌었는지, AI가 채택/보류한 이유 | 사람의 독립 리뷰나 사용자의 최종 만족 |
| 키보드·대상 크기·RAF 검사 | 검사한 조작과 정지·동작 줄이기의 동작 | 전체 WCAG 준수·스크린리더 사용성 |
| 원격 조회·파일 해시 | 조회한 커밋·파일·태그의 일치와 접근 상태 | 실행하지 않은 배포·전달의 완료 |

관찰한 작품은 중국 수묵·채색과 일본 수묵·채색을 구분한다. 한국 수묵·담채의 대표 조사, 특정 화가의 화풍 복제, 물·안료·종이의 물리 시뮬레이션을 주장하지 않는다. 외부 원작을 앱의 자체 출력으로 표시하지 않으며, 생성 도판과 원본 링크를 구분한다.

사용자가 판단할 항목은 꽃과 잎의 비율, 여백과 추상화 정도, 담채의 색감, 선호 브러시, 작품으로서의 최종 만족이다. **사용자 직접 미적 승인은 확인 대기**다. 기술 작업의 위임·자동 시험 통과·독립 AI 리뷰·저장소 공개를 그 승인으로 해석하지 않는다.

v12의 과밀·반복, v13의 옅은 연결, v14의 수정과 I3 부분 채택은 [비교 기록](comparison.md)에 남긴다. [독립 시각 리뷰](visual-review.md)와 [코드 리뷰](code-review.md)도 AI의 작업이다. 성장 중 잎 분리의 전후 실제 PNG와 기하 계산은 다른 증거이며, 계산한29.2px를 실제 화면에서 잰 거리로 쓰지 않는다. 실제 성능 수치도 한 환경의 제어 변경·RAF 관찰이며 기기 전체의 성능 보증으로 일반화하지 않는다.

이후 개선이 성공해도 이전 실패 관찰은 삭제하지 않는다. 시험의 실제 범위는 [tests.md](tests.md), 공개와 파일 전달의 실제 상태는 [delivery.md](delivery.md)를 따른다. 새 원격 업로드가 확인되기 전에는 이미 public인 저장소의 v11 검증을 v14 전달 완료로 대신하지 않는다.
