# 실제 수정·발전 비교

평가 기준은 requirements.md에서 먼저 고정했다. 점수나 사용자 선호를 추측해 수치화하지 않는다. 아래 시각 관찰은 AI의 판단이다.

## v0 — 실행 가능한 최소 기능
실행: evidence/v0-run.json. 원본 화면: v0-desktop.png / v0-mobile.png / v0-canvas.png.
통과한 자동 시험: 결정론/형상 2개, 클릭·정지 버튼 상태·초기화·PNG·가로 넘침 smoke.
부족점: 원형 잎과 비등방 배율 때문에 도식처럼 보임, 우측 수관 잘림, 키보드 심기/모션 감소 미구현. 이는 실제 화면과 코드를 보고 기록했다.

## 실험 1 — v0→v1 (실행 전 가설)
- 의도: 살아 있는 식물로 읽히는 형태와 정돈된 풍경.
- 원인 가설: x/w와 y/h의 다른 배율이 가지를 눕힌다. 원형 끝점은 잎 방향을 전달하지 않는다.
- 변경 예정: 동일 축 배율, 곡선 가지, 방향성 있는 잎, 제한된 잎색, 층진 지면, 미세한 직접 생성 질감.
- 회귀 확인 예정: 같은 seed 데이터, 클릭/정지/초기화/PNG/모바일 overflow, 동일 고정 조건 PNG.
- 실제 실행·관찰·채택 판정: 아직 대기. 아래 후속 기록으로만 추가한다.
