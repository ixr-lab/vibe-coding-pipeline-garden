# 꽃잎 브러시 전달 상태

최신 구현은 v11이다. v5를 기준으로 v6 첫 적용과 v7→v8→v9→v10→v11의 실제 화면 개선을 소스 태그/PNG/결과 JSON으로 보존했다. [전체 비교](comparison.md), [8단계 연결](eight-stages.md), [재현](reproduce.md), [시험과 한계](tests.md).

기술 검증과 독립 시각 검토는 완료했다. P1/P2/P4/P5/P6 충족, P3 수채 세부 충실도는 부분충족이다. 사용자 직접 미적 승인은 **확인 대기**다. 이 문서 작성 시점에는 최종 이력 감사와 원격 전달 검증을 진행 중이며 공개 상태를 아직 완료로 선언하지 않는다. 아래에 실제 원격 결과를 추가한다.

전달 파일은 저장소의 코드·한국어 문서·자체 PNG와, 별도로 만든 최종 ZIP/대표 PNG다. Library에는 이전 파일을 덮어쓰지 않는 신규 파일로 전달하며 실제 파일 ID와 ZIP 해시는 도구 영수증 및 최종 보고에 기록한다. ZIP에는 `.git`, 계정 정보, 외부 원본 사진/회화, 다른 프로젝트의 비공개 자산을 포함하지 않는다.

## 원격 전달 확인 후 추가 기록

위 문단은 검증 전의 작성 상태를 보존한다. 이후 v11 소스 태그 `5967d30ebe8e630cc4c55e263092076986bd2cdd`, 최종 검증 문서 커밋 `cd38356430bcffd8ae80212641b31bf7ad594a20`을 실제 push하고 public 전환을 완료했다. [원격 검증 JSON](../../evidence/petals/publication-remote.json)은 주요 파일 29개 바이트 일치, v0~v11 태그 12개 일치, 비인증 README·코드·PNG 3개 HTTP 200 및 바이트 일치를 기록한다. 첫 Git 읽기의 일시적 403 뒤 API의 `disabled:false`와 비인증 조회 성공을 확인했으며, 가시성 변경 명령은 반복하지 않았다. OAuth 권한 추가와 Pages 배포는 하지 않았다.

전달을 마무리하던 중 수묵·담채, 색 선택, 전체 식물 비율의 새 요청이 도착했다. v11 이력은 유지하고 [후속 계획](../ink/plan.md)으로 진행한다. v11 전용 ZIP은 추가하지 않았으며 새 최종 전달 묶음에 이 이력을 포함한다. 기존 Library 파일은 유지한다.
