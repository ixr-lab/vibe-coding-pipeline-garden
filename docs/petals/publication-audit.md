선정된 이력에서 인증 토큰·개인 키·개인 사용자 경로·대화 전문 표식은 발견하지 못했다. 작성자와 커미터는 예시용 `Garden Example` 및 프로젝트의 noreply 주소였다. 원본 이력 재작성이 필요한 핵심 차단 사항은 발견하지 못했다.

같은 프로젝트의 이전 ZIP을 가리키는 Library 파일 식별자는 인증 토큰이 아니며, 식별자 자체가 접근 권한을 부여하지 않는다. 공개 독자가 사용할 수 없는 내부 전달 정보이므로 문서에서 공개할 필요성은 별도로 판단할 수 있다. 이 식별자만으로 이력 삭제가 필요한 비밀 노출로 분류하지 않았다. 식별자 원문은 이 문서에 복제하지 않는다.

## 외부 자산과 권리 범위

`reference-source/flowers.json`, `brushes.json`, 후속 `petals.json`과 관찰 문서는 출처·저작자·권리·직접 본 범위·미확인을 기록한다. 외부 원본은 링크로 제시하고 제품의 그림은 자체 Canvas 코드 출력으로 제공한다. 관찰한 파일에서 원본 사진·공식 샘플의 저장소 재배포나 다른 기존 프로젝트의 자산은 발견하지 못했다.

이 결론은 읽은 파일과 실제로 확인한 도판의 범위다. 링크된 모든 원본의 과거 관찰과 라이선스 확인을 이번 감사에서 다시 실행한 것은 아니다. PNG 바이트나 파일명 검사로 이미지의 원출처·저작권을 증명할 수 없다. 새 외부 이미지·프리셋·폰트 등을 넣는 경우에는 해당 자산의 재배포 조건과 실제 배포물을 다시 확인한다.

## 재현용 로컬 검사

```powershell
python scripts/publication_audit.py
```

결과는 `evidence/petals/publication-local.json`에 저장한다. 스크립트는 존재하는 `main`과 `v0`~`v11` ref의 정확한 객체 ID만 출발점으로 사용하고, 다른 ref·reflog를 열거하지 않는다. 아직 없는 태그는 `missing_optional_refs`에 기록한다. Git replace와 객체 자동 다운로드도 끈다. 현재 HEAD 포함 여부, 객체·경로 수, 작성자, 민감 패턴, PNG chunk/비PNG 바이너리, 현재 작업 파일과 검사 전후 ref 변동을 기록한다. 발견 원문·토큰·개인 작성자 값은 출력하지 않는다. 자체 정규식은 해당 문자열 토큰 범위만 오탐에서 제외한다.

현재 파일 검사는 tracked 및 ignore되지 않은 untracked 배포 후보를 대상으로 하고, 링크를 따라가지 않는다. 결과 JSON 자체는 재귀 검사를 피하기 위해 현재 파일 스캔에서 제외한다. Git 이력·작업 파일·권한·공개 상태는 변경하지 않으며 보고서만 쓴다.

종료 코드 `0`은 자동 검사 발견 없음, `1`은 발견 또는 검토 필요, `2`는 검사 미완료다. 자동 검사 통과는 권리 보증이나 시각 품질 승인, 공개 전환 승인을 의미하지 않는다.
