# 꽃잎 브러시 실제 작업 로그

## v5 기준과 v6 첫 구현 — 실제 실행
2026-10-17 02:54 UTC. v5 태그를 저장소 밖 실행용 폴더에 추출하고 새 비교 harness만 얹어 캡처했다. 첫 실행은 상대경로 as_uri 오류로 중단했고 resolve 수정 후 재실행했다. baseline 검사는 13개 중 7개 통과, 꽃머리 브러시 해시가 동일한 6개 항목은 의도한 실패로 보존했다. 원래 v5 소스는 변경하지 않았다.

v6는 꽃잎 Path2D를 유지하고 그 안에 재료별 방향성 획을 겹쳤다. 같은 기하 seed로 확대 radius105와 기본 radius23에서 15개 꽃머리를 캡처했다. Chrome 155에서 22/22 검사 통과(픽셀 차이·결정성·4개 조절 왕복·고정 결 안정·모바일 넘침·예외). 이것은 미적 적합 판정과 별개다.

제작자가 v6-large/basic PNG를 직접 확인했다. 종은 유지되고 5개 차이는 보이나, 먹은 넓고 각진 리본 때문에 금속 주름 같고, 드라이는 구겨진 조각처럼 복잡하며, 수채는 큰 둥근 밝은 얼룩으로 읽힌다. 기본 크기에서도 먹/드라이는 과하고 연필은 매끈한 무광에 가깝다. v6 채택은 보류한다. 다음 가설: 먹 폭·명암을 줄이고 드라이는 가는 결속 붓털과 종이 빈틈, 수채는 기부→끝의 긴 투명 겹침으로 바꾸면 곡면을 덜 가릴 것이다. 독립 리뷰를 요청했다.

## v7 첫 개선 — 관찰과 다음 가설
2026-10-17 02:58 UTC. 먹의 폭/명암을 줄이고 다각형 윤곽을 곡선으로, 드라이를 가는 붓털 묶음과 공유 끊김으로, 수채를 원형 대신 긴 투명 곡률 띠로, 연필을 방향성 해칭으로 바꿨다. 같은 조건의 v7-large/basic/garden을 실제 캡처했다. 개별 데이지 꽃머리의 모든 재료×두 배율×4개 조절 효과·왕복 40항목을 추가해 62/62 통과했다.

제작자 관찰: 큰 원형 얼룩과 구겨진 조각은 크게 줄어 꽃잎 면이 회복되었다. 그러나 기본 크기에서 5재료는 더 비슷해졌다. 특히 동일한 진한 밑칠 위에 가는 획만 얹는 방식은 작은 꽃에서 차이가 사라진다. P5는 계속 미달로 기록한다. v7 일부 채택(구김·원형 제거), 기본 크기 표현은 보류. 다음 가설: 종의 윤곽을 그대로 두고 재료별 바탕의 밝기/농도와 획 묶음·종이 노출 면적을 달리하면 단순한 픽셀 차이를 넘어 기본 크기에서도 읽힐 것이다. 독립 재검토 요청.
