# 꽃잎 붓질 관찰 기록

관찰일: 2026-10-17. 이 문서는 `reference-source/petals.json`의 근거와 구현 판단을 설명한다. 목표는 실제 꽃의 실루엣을 유지하면서 붓으로 칠한 꽃잎의 방향·넓고 좁은 면·여백·겹침을 표현하는 것이다. 사진 수준의 표면 복제나 특정 회화의 구도 복제를 목표로 하지 않는다.

## 확인 방법과 이미지 보관

공식 작품 페이지에서 제목·작가·재료·권리 표기를 확인한 다음, 아래 JPEG를 내려받아 **각각 `view_image`로 실제 픽셀을 직접 보았다.** 다운로드 성공 또는 텍스트 설명만으로 시각 관찰했다고 기록하지 않았다. 작품의 표면 효과 관찰과 디지털 구현 제안을 구분했다.

모든 이미지 사본은 코드 저장소 밖의 `../petal-reference-study/`에만 보관했다. 제품 정적 자산·코드 저장소·Library에는 외부 이미지나 잘라낸 부분을 복제하지 않았다. 이 저장소에는 출처 링크와 자체 작성 관찰만 추가한다. 아래 파일명은 로컬 재현용이며 제품 경로가 아니다.

세 작품은 판화가 아닌 실제 채색 작품이다. Redouté 소개문에 인쇄 출판 경력이 나오더라도 이 특정 물건의 재료는 양피지 위 수채와 금이다. Seitei의 이 작품은 목판 화보가 아닌 비단 위 먹과 채색이다. Sōsetsu 작품은 공식 페이지의 **Attributed to**를 유지한다. Met는 비슷한 I’nen 인장을 여러 화가가 사용해 정확한 제작자를 확정하기 어렵다고 설명한다.

Met의 [Open Access 안내](https://www.metmuseum.org/hubs/open-access)는 공공영역 작품 이미지를 CC0로 제공한다고 명시한다. 이는 각 작품 페이지의 Public Domain 표기와 함께 확인했다. 기관 전체의 일반 안내만으로 개별 이미지의 권리를 추정하지 않았다.

사진은 붓질의 근거가 아니라 종별 형태의 근거다. 특히 코스모스·데이지의 눈에 보이는 큰 꽃잎 모양 부분은 설상화이므로, 실제 꽃잎 한 장과 완전히 동일한 식물학적 단위라고 설명하지 않는다.

## 브러시별 관찰과 적용

### `petal-watercolor` — 면을 남기고 곡률을 따라 칠하기

**직접 관찰.** Redouté의 꽃에서는 노랑의 안쪽 면, 붉은 바깥쪽 면, 밝게 남은 좁은 경계가 굽은 꽃잎의 방향을 설명한다. 물결치는 끝은 있으나 안쪽 전체를 같은 선으로 덮지 않는다. 가는 길이 방향 칠 자국은 특히 잎에서 보인다. 잎의 표면 결을 꽃잎의 실제 잎맥으로 설명하지 않는다.

**기부→끝과 곡률.** 구현의 주축은 꽃잎의 기부에서 끝으로 휘는 곡선이다. 곡선의 접선을 따라 소수의 성긴 결이 나아가고, 꽃잎이 기울면 결도 함께 휜다. 코스모스의 넓은 설상화에는 부채꼴 확장을, 데이지에는 길게 좁은 결을, 양귀비에는 큰 접힘을 유지한다.

**겹침·여백·외곽선.** 옅은 기본 면에 국소적인 짙은 띠를 더하고 반대편에는 밝은 면을 남긴다. 반투명 색띠를 겹치는 것은 구현 선택이다. 원작의 물감이 실제로 얼마나 투명한지 또는 투명 도막을 어느 순서로 칠했는지는 이미지로 확정하지 않았다. 외곽선은 겹침 아래나 접힌 짧은 한쪽에만 허용하며 전 둘레를 같은 선으로 닫지 않는다.

**압력 표현.** 결이 좁게 시작해 일부 넓어졌다가 가늘게 끝나는 변화로 눌림과 들어 올림을 연상시킨다. 이는 원작의 필압을 측정하거나 복원한 결과가 아니다. 균일한 가장자리 흐림만으로 수채 효과를 대신하지 않는다.

### `petal-ink-hatching` — 기부에 모이고 밖으로 성겨지는 선

**직접 관찰.** Sōsetsu 귀속작의 흰 꽃은 밝은 면이 넓고, 가는 어두운 선은 컵 모양 기부에 모여 바깥으로 벌어진다. 일부 선은 짧게 끝나고 중앙 면에는 빈 부분이 남는다. 따뜻한 회갈색 외곽은 부분적으로 강하며 모든 가장자리가 같은 굵기로 연결되지 않는다. 공식 재료가 color and gold on paper이므로 보이는 선의 안료를 먹으로 확정하지 않는다.

**기부→끝과 곡률.** 해칭은 꽃잎 국소 곡선을 따르는 부채꼴이다. 같은 화면 각도의 평행선이나 같은 직선의 회전 복제를 사용하지 않는다. 선 사이 간격·길이·곡률이 조금씩 달라지고 기부에서 바깥쪽으로 밀도와 농도가 낮아진다.

**겹침·여백·외곽선.** 해칭의 목적은 접힘과 겹침을 읽게 하는 것이다. 전체 꽃잎에 등간격 선을 채우지 않고 중앙과 끝의 밝은 여백을 남긴다. 앞 꽃잎이 가리는 구간에는 짧은 어두운 경계를 허용한다. 기부에서 시작하는 모든 선이 끝까지 이어지거나 모든 꽃잎이 폐곡선으로 둘러싸이지 않게 한다.

**압력 표현.** 선 중간의 작은 폭 변화와 끝의 가늘어짐은 디지털 붓의 제안이다. 회화에서 실제 한 획의 시작·끝·필압을 확정하지 않았다. 겹꽃처럼 보이는 회화의 양귀비 외형은 구현 대상 Papaver rhoeas의 형태 근거로 사용하지 않는다.

### `petal-pressure` — 넓은 색면과 가는 끝의 리듬

**직접 관찰.** Seitei의 푸른 꽃차례는 작은 둥근 면·물방울 모양의 짙고 옅은 색면과 그 사이 빈틈으로 읽힌다. 모든 작은 꽃잎에 외곽선을 그리지 않는다. 넓은 몸체와 가는 끝의 폭 변화는 큰 잎에서 더 분명히 보인다. 잎에서 보인 특성을 꽃잎의 세부 운필을 직접 확인한 사실로 바꾸지 않는다.

**기부→끝과 곡률.** 폭의 변화는 꽃잎의 긴 곡선 위에서 진행한다. 폭이 넓어지는 구간과 가늘어지는 구간을 연결하되, 종별 마스크 안에서만 붓결을 그린다. 특히 데이지의 끝은 실제 사진에서 둥글거나 얕게 갈라지므로 한 획의 뾰족한 물방울 윤곽으로 대체하지 않는다.

**겹침·압력·여백.** 넓은 옅은 면과 좁은 짙은 결을 함께 허용한다. 폭과 농도를 하나의 값에 완전히 묶으면 단순한 그라데이션 도장이 되기 쉽다. 주된 넓은 칠은 소수로 제한하고 밝은 내부 면과 꽃잎 사이의 틈을 따로 보존한다. 실제 필압·속도·물의 양·한 획 여부는 관찰로 확정할 수 없으며 디지털 설계 변수로만 쓴다.

**허용 외곽선.** 진한 작은 색면으로 겹침을 설명하고 전체 외곽선은 필수로 쓰지 않는다. 외곽선이 필요할 때도 기부나 가려진 짧은 경계에 한정한다.

## 관찰의 한계와 검토 기준

- 제공 JPEG는 높이 1200px이며 개별 꽃이 작다. 미세한 붓털 자국, 안료 종류, 재료의 흡수 정도, 정확한 칠 순서와 물리적인 압력을 측정한 근거는 없다.
- 양피지·종이·비단은 다른 바탕이다. 세 작품에서 보인 시각 효과를 모두 수채화지의 번짐으로 일반화하지 않는다.
- 회화 속 Gloriosa, 겹꽃 양귀비, 작은 푸른 꽃의 형태를 대상 세 꽃에 이식하지 않는다. Seitei의 푸른 꽃은 카탈로그가 종을 특정하지 않으므로 등나무라고 확정하지 않는다.
- 기부→끝 결이 곡률을 따라가는지, 겹침 한쪽만 어두운지, 내부의 밝은 여백과 꽃잎 사이의 틈이 남는지, 부분 외곽선의 강약이 있는지를 실제 렌더 이미지에서 검토해야 한다. 이 문서는 구현 후 시각 검토를 완료했다는 주장을 하지 않는다.
- 이번 관찰에서 열지 못한 출처를 관찰 완료로 기록하지 않았다. Charles Demuth의 [Red Poppies](https://www.metmuseum.org/art/collection/search/482725)는 공식 페이지가 이미지 확대·다운로드를 허용하지 않는다고 표시해 이미지 저장과 최종 회화 참고에서 제외했다. Smithsonian의 검색 후보는 공식 항목 URL이 404여서 사용하지 않았다.

구현 채택 여부와 렌더 비교 결과는 별도의 구현 검토에서 남긴다. 이 문서의 제안 수치는 표현상의 시작점이며 식물의 측정값이나 원작의 물리적 제작 기록이 아니다.
