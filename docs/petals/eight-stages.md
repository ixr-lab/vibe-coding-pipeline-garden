# 꽃잎 브러시 후속 사례의 8단계

원래 v0→v1→v2 사례와 꽃/줄기 확장 v3→v4→v5를 보존한 후속 작업이다. 아래는 실제 수행한 일의 연결이며, 새 사용자 승인이나 수행하지 않은 시험을 보충한 타임라인이 아니다.

| 단계 | 이번에 남긴 근거 |
|---|---|
| 1 목표와 맥락 | v5에서 꽃머리 열이 같음을 확인. 줄기뿐 아니라 꽃잎에도 선택한 재료를 적용하는 목표와 P1~P6/T1을 [계획](plan.md)에 고정 |
| 2 레퍼런스와 비교 기준 | 공식 미술관 회화3점/실물사진3장 실제 열람, [관찰·추론·권리 구분](reference-observations.md), 정규 JSON과 생성된 보드. 확대/기본을 함께 판단 |
| 3 설계와 범위 | 기하 Path2D 유지, clip 내부 로컬 획, 옵션별 cache key, 제어 하나 추가. 기술 범위는 요청에 따라 진행하고 사용자 미적 승인을 얻었다고 간주하지 않음 |
| 4 최소 구현 | v6 태그와 확대/기본/정원/모바일 캡처, v5의 실제 실패와 v6 기능 통과를 함께 보존 |
| 5 실행과 레퍼런스 비교 | 제작자 및 독립 리뷰어가 원본과 실제 PNG를 열어 비교. 자동 픽셀 차이가 있어도 v6 P5/P6 미달로 기록 |
| 6 원인 가설과 반복 | v7 폭/구김/점 개선 → 기본 차이 약화 → v8 바탕/빈틈 → 반복선/색필름 미달 → v9 추가 개선 → v10 표면 재구현 → v11 픽셀 폭 제한 보정. [로그](log.md)와 [비교](comparison.md)의 의도→가설→변경→실행→관찰→채택/보류 |
| 7 통합과 의도 판정 | [시험과 한계](tests.md), 기본/확대/실제 정원 비교, 독립 코드 리뷰와 시각 판정. 기술 통과·제작자/리뷰어 유사도·사용자 취향을 분리 |
| 8 전달과 재사용 | 기존 v0~v10 증거와 Library 파일 보존, [재현 지침](reproduce.md), 새 ZIP/PNG, 같은 저장소 원격 재조회와 공개 사전 감사. 최종 전달 상태는 [delivery.md](delivery.md) |

AI는 기하·재료 모듈, 출처 관찰, 테스트, 코드 리뷰, 시각 리뷰를 역할로 나누었다. 독립 AI 리뷰는 사람의 승인이나 사용자 조사 결과가 아니다. 사용자가 직접 판단할 항목은 색감·추상화 정도·좋아하는 브러시·작품으로서의 최종 만족이며 현재 **확인 대기**다.
