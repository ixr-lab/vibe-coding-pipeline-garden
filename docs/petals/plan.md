# 꽃잎을 그리는 브러시 — 실행 전 기준

2026-10-17 UTC. 사용자 후속 요청: 다섯 브러시가 줄기뿐 아니라 꽃잎의 외곽/내부에 영향을 주고, 사실적인 형태를 유지한 회화적 표현으로 발전시킨다. 이전 버전·private 저장소·Library 원본은 보존한다. 사용자 미적 승인은 확인 대기다.

## v5 실제 화면 진단
v5-flowers.png와v5-combinations.png를 직접 열었다. v5의 꽃머리는 브러시 열 사이 동일하다. 코스모스의 일정한 방사선과 각진끝, 데이지의 청회색 긴 홈/구슬 같은 중심, 양귀비의 큰 그라데이션 면이 벡터 인상을 만든다. 일부 겹침은 있으나 모든 꽃이 비슷한 정면 각도다. 선택브러시의 재료 차이는 줄기에만 보인다.

## 프로토콜·구현 선택
v5 baseline과v6/v7/v8 꽃머리 접촉시트: seed271828, 같은꽃종별geometryseed/tilt=-.1/재료width1/texture60/opacity85/strength65. 확대radius105,기본radius23. 전체정원 seed271828/density7/wind35/frame360/viewport1440×1000/DPR1. 전체UI변경에따른Canvas높이는기록하고머리만의도판으로재료효과를분리한다.

선택브러시를재사용하되각꽃잎의곡선실루엣에clip해내부방향성묘사. 새petal-paint.js는재료전용,flower-art.js는종별path/깊이순서와옵션전달,PlantRenderer는옵션/seed/scale/age별spritecache. 꽃잎표현강도조절하나를추가하고기본UI과밀은재료details로완화한다. v5 API 호출은원형비교를위해보존한다.

## 실제 진행 순서
v5 고정baseline확보 → v6 최초꽃잎브러시실행 → 실제이미지비교/가설 → v7 첫수정 → 재관찰/독립리뷰 → v8 두번째수정 → 최종회귀/성능/레퍼런스동기화/원격정확바이트검증/별도ZIP과PNG Library전달.

사진급/사용자만족/실제화구의물리재현을주장하지않는다. 실패와부분채택·미달은작업중기록한다.
